# Layerly

E-commerce platform for 3D-printable designs: designers upload and sell their models, customers buy and download them.

**Live demo:** https://layerly-capston-project-tonyf.netlify.app
> Backend on Render and database on Neon (free plans): the first load can take about 50 seconds.

## Tech stack
React, TypeScript, Redux, React Router, React-Bootstrap, Sass · Java, Spring Boot, Spring Security (JWT), PostgreSQL, Flyway
